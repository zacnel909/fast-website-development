Start a new project

  1. Create the repo from this template

    gh repo create my-idea --private --clone \
  --template zacnel909/fast-website-development
cd my-idea

  2. Name the subdomain

    Set "subdomain": "my-idea" in site.config.json. That's the only required edit.

  3. Iterate locally

    npm install
npm run dev

    The dev server listens on your LAN. Open the Network URL it prints on your phone.

  4. Deploy

    aws sso login --profile magic-of-words   # if needed
npm run deploy

    The first run creates the bucket, CloudFront, and DNS (a few minutes). After that, each deploy takes about 15 seconds. You don't need to commit or push.

Static by default

S3 + CloudFront with the shared wildcard cert. HTML revalidates on every load, so a refresh shows the latest deploy.

Dynamic when needed

To add an API, give the same distribution an /api/* behavior pointing at a Lambda. No change of host required.

Local credentials only

Deploys use your SSO session. No secrets in GitHub, no long-lived keys.
